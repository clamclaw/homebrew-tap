# ClamWake Homebrew Tap

[Homebrew](https://brew.sh) casks for Mac apps by ClamWake.

## CMD HitoTap

Press the left ⌘ alone for Eisu (English) and the right ⌘ alone for Kana (Japanese).

```bash
brew install --cask clamclaw/tap/cmdhitotap
```

CMD HitoTap updates itself, so `brew upgrade` leaves it alone. See [clamclaw/cmdhitotap](https://github.com/clamclaw/cmdhitotap) for details, or download the DMG from the [website](https://clamwake.com/cmdhitotap/).
